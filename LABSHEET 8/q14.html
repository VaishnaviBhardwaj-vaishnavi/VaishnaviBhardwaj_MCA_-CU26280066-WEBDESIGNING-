Design Rationale Document

Project Name

The Golden Crust Bakery Website

Color Selection

Brown represents warmth and trust. Cream represents cleanliness. Beige creates a natural bakery appearance.

Typography

Arial font is used because it is simple, readable and easy to understand.

Target Audience

Students, families, working professionals and bakery customers.

Layout Design

CSS Grid and Flexbox are used for responsive website layout.

Accessibility

Alt text, semantic HTML and proper labels are used for accessibility.

Conclusion

The website provides an attractive, responsive and user-friendly experience.
